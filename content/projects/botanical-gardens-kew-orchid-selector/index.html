The Orchid Selector is a Final year Project being developed by a fellow student for the Botanical Gardens, Kew. The system is a knowledge-base query system, allowing users to identify orchids by describing some prominent features.

I was asked to develop an XHTML front end for the on-line application. The design needed to be flexible to allow for any amount of data, which would be generated by the AI based back-end, and resemble the exisitng brand developed by the gardens, using the same pallette where possible.

A simple page structure is arranged using CSS to ensure that the page will be presentable at any size or resolution.
